# 星语 · Starlit Words
### 让每一句话都变成一颗星的 SillyTavern 扩展

你和角色说过的每一句话，都会变成背景里的一颗小星星。
而那些你想永远记住的话，可以亲手把它摘下来，变成一颗珍藏星。

---

## 安装方法

1. 打开 SillyTavern
2. 点顶栏的 **积木图标**（扩展）
3. 点 **「Install extension」（安装扩展）**
4. 粘贴此仓库地址
5. 弹出「第三方扩展」提示时点 **Yes, install it**
6. 安装完成后**刷新页面**

---

## 怎么用

| 功能 | 说明 |
|------|------|
| ✨ 每句话一颗星 | 每发送或收到一条消息，就有一个光点从输入框升起，飘到天上变成星星，均匀洒满整片天空 |
| 🌟 珍藏一段话 | 在消息里拖选（手机上长按）你喜欢的一段文字，点 **「✦ 珍藏这段」**，它就会变成一颗四角珍藏星 |
| 📜 展开文字 | 点击珍藏星，会展开那段话，以及是谁说的、什么时候说的 |
| 📱 手机也能看 | 魔法棒菜单里的 **「珍藏的星星」** 会列出这个聊天的所有珍藏 |
| 🌠 散开 | 珍藏星会自动找天空里最空的地方；也可以点「重新排列本聊天的珍藏星」重新散开 |
| 🗑️ 移除 | 展开文字后，点「移除这颗星」 |
| 🌗 深色 / 浅色 | 自动识别你的主题配色 |

只有你亲手选的片段才会变成珍藏星，AI 无法自己添加。

## 设置面板

在扩展设置里找 **「✦ 星语」**：

| 选项 | 说明 |
|------|------|
| 色系 | 月白·金 / 樱·玫瑰金 / 冰川·银白 / 极光·淡紫 / 烛火·珊瑚 / 紫藤·淡金 |
| 亮度 | 星星整体亮度 |
| 星星大小 | 星星的大小 |
| 开关 | 新消息升起动画 |
| 星图卷轴 | 把珍藏导出成一卷可以用浏览器打开的星图（.html），底色可选「夜空」或「宣纸」，颜色跟随色系 |
| 其他导出 | 纯文字（.md）· 完整备份（.json） |

「全部卷轴」和「全部文字」会收录装好扩展之后打开过的聊天。旧的聊天只要打开一次，就会被收录进去。
