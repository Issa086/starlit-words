# 星语 · Starlit Words
### 让每一句话都变成一颗星的 SillyTavern 扩展

你和角色说过的每一句话，都会变成背景里的一颗小星星。
而那些你想永远记住的话，可以亲手把它摘下来，变成一颗金色的珍藏星。

---

## 安装方法

1. 打开 SillyTavern
2. 点顶栏的 **积木图标**（扩展）
3. 点 **「Install extension」（安装扩展）**
4. 粘贴此仓库地址
5. 弹出「第三方扩展」提示时点 **Yes, install it**
6. 安装完成后**刷新页面**

---

## 怎么用

| 功能 | 说明 |
|------|------|
| ✨ 每句话一颗星 | 每发送或收到一条消息，就有一个光点从输入框升起，飘到天上变成星星 |
| 🌟 珍藏一段话 | 在消息里拖选（手机上长按）你喜欢的一段文字，点出现的 **「✦ 珍藏这段」**，它就会变成一颗金色的四角星 |
| 📜 展开文字 | 点击金色珍藏星，会展开那段话，以及是谁说的、什么时候说的 |
| 📱 手机也能看 | 魔法棒菜单里的 **「珍藏的星星」** 可以列出这个聊天所有的珍藏，点一条就会在天上标出那颗星 |
| 🗑️ 移除 | 展开文字后，点「移除这颗星」 |
| 🌗 深色 / 浅色 | 自动识别你的主题配色 |

- 只有你亲手选的片段才会变成珍藏星，AI 无法自己添加。
- 珍藏保存在每个聊天自己的数据里。换一个聊天，就是另一片星空。
- 可以和「星空 · Celestial Background」一起使用。
